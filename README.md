# Rainvale

Уютная пиксельная игра про хутор под вечным дождём. Собираешь дерево, камни, цветы и тростник, мастеришь доски, кирпич, ткань и краску, свободно строишь домик, сад и дорожки. Звери приходят в гости туда, где им нравится. Без голода, монстров и смерти.

## Запуск

```bash
npm install
npm run dev
```

Игра откроется на http://localhost:5199.

## Управление

- WASD — гулять, клик — подойти и собрать или пойти туда
- Пробел (держать) — собирать всё рядом
- E — мастерская (инструменты, материалы, стройка), в режиме стройки можно вести мышью
- M — звук вкл/выкл
- 1–9, колесо — выбрать ячейку пояса
- X — убрать постройку, материалы возвращаются целиком
- J — дневник гостей

## Устройство

- `src/game/defs.ts` — материалы, рецепты, постройки, природа, гости
- `src/game/world.ts` — карта 96×96, генерация, сохранение
- `src/game/game.ts` — цикл, игрок, гости, стройка, сад, погода
- `src/game/render.ts` — отрисовка, свет, дождь
- `src/game/art.ts` — все спрайты рисуются кодом
- `src/components/` — интерфейс на Vue
